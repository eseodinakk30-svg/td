# Разлом

Пошаговая Android-игра про персонажей мультивселенной. Ты — ходок по разломам:
вытаскиваешь бойцов из схлопывающихся вселенных, собираешь отряд из трёх
и спускаешься всё глубже, где навстречу выходят искажённые эхо.

## Как играть

1. **Призыв.** На выбор три бойца из разных вселенных. Смотри на роль,
   характеристики и способность — они определяют стиль боя.
2. **Лагерь.** Здесь виден отряд и состояние каждого. Отсюда идёшь в бой.
3. **Бой.** Пошаговый: атака, способность за энергию или фокус
   (+2 энергии и щит). Можно менять активного бойца — но ход при этом
   переходит врагу.
4. **Глубже.** После победы отряд подлечивается, павшие возвращаются
   ослабленными, а разлом уводит на следующую глубину. Забег кончается,
   когда падает весь отряд. Лучшая глубина сохраняется между запусками.

## Вселенные

| Вселенная | Черта | Способность |
|---|---|---|
| Неоновый Спрол | Скорость | **Разгон** — два удара подряд, высокий шанс крита |
| Пепельная Империя | Ярость | **Клятва крови** — тяжёлый удар ценой своего здоровья |
| Изумрудная Глубь | Регенерация | **Цветение** — лечение и снятие горения |
| Хромовая Пустота | Щиты | **Эгида** — щит, поглощающий урон |
| Двор Углей | Горение | **Взрыв углей** — урон и поджог на 3 хода |
| Стеклянный Реквием | Фазы | **Фазовый сдвиг** — уклонение и контрудар |

У каждой вселенной своя палитра и силуэт. Картинок в проекте нет вообще:
все персонажи собираются процедурно из фигур на `Canvas` по зерну бойца,
поэтому двух одинаковых не бывает.

## Где взять APK

Сборка идёт в GitHub Actions — workflow `.github/workflows/build-apk.yml`
запускается на каждый push в ветку и на `workflow_dispatch`.

1. Открой вкладку **Actions** → прогон **Build APK**.
2. Внизу страницы прогона, в разделе **Artifacts**, скачай `rift-debug-apk`.
3. Распакуй архив и установи `app-debug.apk` на телефон
   (потребуется разрешить установку из неизвестных источников).

APK собирается в debug-варианте и подписан отладочным ключом — он
устанавливается и работает, но для публикации в Play нужна отдельная
подпись релизным ключом.

## Сборка локально

Нужен Android SDK (platform 34) и JDK 17:

```sh
./gradlew assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как устроено

Никаких внешних зависимостей — только Kotlin stdlib и framework Android.

| Пакет | Что внутри |
|---|---|
| `model` | `Universe`, `Ability`, `Fighter` — данные и состояние бойца |
| `game` | `Roster` и `NameGen` (генерация), `Battle` (боевой движок), `GameState` (поток экранов) |
| `render` | `Theme` (палитра), `Avatar` (процедурные силуэты), `GameView` (весь UI и ввод) |

Интерфейс рисуется в режиме immediate mode: `GameView` на каждом кадре
перерисовывает экран и заново регистрирует «горячие зоны» кнопок, а
обработчик касаний просто ищет попадание среди них. Боевая логика ничего
не знает про Android — она отдаёт журнал событий и всплывающие числа,
а цвета и анимации подбирает уже рендер.
